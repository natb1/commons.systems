# Draft and land about-page copy presenting the three service lanes with lane-attributable direct-email intake

Retained context from the 2026-07-06 /align-strategy interview. The author's
lane mapping, verbatim from the requirement text:

> The about page on the landing needs to funnel opportunities for three
> different types of services (all described generally by the content that is
> already there.
>
> - Project management (application the intention/ graph data structure and
>   office-hours ui project)
> - Custom software development (I develop custom software by creating the
>   intention/ graph and using the dispatch router harness to develop the
>   software)
> - AI consulting / systems integrator / \<the industry standard name for
>   this\> (I advise enterprises on incorporating LLM into their workflows
>   using the intention/ graph data structure and long horizon harness as a
>   model)

Copy-relevant interview resolutions (full record on
`strategy-services-funnel`):

- Lane 3's industry-standard name is **AI systems integrator**. Never use
  "AI transformation" — the page itself promises "No transformation, no
  migration", and the brand rules bar the jargon.
- One practice, three doors: present the lanes as engagement shapes of one
  practice (the intention graph + long-horizon harness), not three separate
  businesses.
- Author-operated framing: the client consumes outcomes (plans, status,
  software, advice), never a seat in the author's tooling — no tier-2
  dependency, and the copy must not promise product access.
- Audience: the landing is the tier-2/business-stakeholder surface; write for
  buyers, keep practitioner material in the README.
- Intake: direct email to nathan@natb1.com, attributable by lane (so the
  strategy's inquiries-by-lane signal can be read from the inbox) — no CRM or
  lead-gen service.
- The existing page copy (landing/src/pages/About.tsx) already describes the
  practice generally; the funnel names the lanes without discarding the
  standing promises (capability not dependency, data stays yours, deliberate
  third-party dependencies, retainer contracts).
- Consult the `brand` skill before drafting; the strategy's office_hours park
  is the author's review gate — copy work starts only after the park clears.
