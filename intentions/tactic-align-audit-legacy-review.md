## Retained engine 1 — the rung-5 dialectic (scheduled align jit review)

A decompose → assess → synthesize → challenge → re-synthesize loop over
evaluative perspectives, run scheduled with no human present, triaging the
open backlog and producing recommended re-prioritizations, strategy-doctrine
edits, and backlog edits. Components:

- **Two orthogonal layers, never conflated.** Structural roles drive the
  dialectic (universal, project-independent); perspectives are the evaluative
  lenses the roles run over (intrinsic financial + technical, always applied;
  charter-derived roster — at retirement: product, marketing — re-derived
  each run by the decomposer from the virtue roots, never hardcoded).
- **Structural roles** (agent defs retired with the engine):
  align-decomposer (emits the perspective roster at rung-5);
  align-consistency (the veto layer: charter compliance, dependency health,
  ratchet risk — findings, not priorities; a critical finding can veto);
  align-delegability-assessor (per intention node: CAN → SHOULD → consistency,
  one delegability.eval.v1 object per the ref-delegability contract);
  align-contrarian (one concentrated adversarial pass over the synthesis — a
  deliberate concentration replacing the older 5-way per-persona review);
  align-signal-assessor (per node: classify → economics → output, one
  signal.eval.v1 per the ref-signal-identification contract).
- **Two axes, never conflated**: decomposition (intention → sub-intention →
  goal) vs delegation (human → AI → procedure, a per-intention continuum).
- **Flow**: assessment window → Phase 1 gather context (gather-context.sh,
  fetch-analytics, fetch-psi: frontier view, work since last review, GA4
  analytics, web-vitals/PSI) → Phase 1.5 decompose (perspective roster) →
  Phase 2 independent per-perspective assessments → Phase 3 synthesize
  (scored priorities) → Phase 4 contrarian challenge → Phase 5 re-synthesize
  → backlog issue-triage → recommendations: (1) frontier & strategy
  recommendations, (2) proposed charter revisions, (3) existing issues to
  update, (4) new issues to file, (5) per-priority delegability findings →
  terminal behavior: post the report on the jit review issue and close it to
  anchor the next cycle. Plus a per-intention "automate" push-down pass.
- **Anti-calcification role**: the contrarian and consistency passes were a
  named mechanism keeping recorded doctrine from calcifying into dogma
  (strategy-explicit-intent, anti-calcification clarification) — weigh this
  when deciding whether /align-audit's contrarian-free mechanical audit
  suffices, or the sitting cadence carries it.

## Retained engine 2 — the /align-strategy improvement pass (no-text branch)

Read every strategy node; for each, check: (a) any attributes.conditions
entry that no longer plausibly holds against current repo/author state;
(b) reading/gap staleness — a reading predating a clarification that should
have invalidated it, or a gap describing a target already met; (c) a
clarifications entry contradicted by a later clarification on the same or a
related node; (d) the greenfield-relevance gate (strategy clarification 26):
sweep open non-draft tactics for subjects deleted or superseded by a
non-draft node elsewhere (a raw draft never obsoletes live work); per-unit
doomed-drop naming the superseding node; demote a tactic to draft only when
fully superseded; doomed-surface keeps require an explicit interim-live-risk
exception naming the expiry event. Separately: census virtue ids appearing in
no strategy's serves — each a candidate for a brand-new strategy. Present all
candidates (failing-condition / stale-signal / contradicted-clarification /
doomed-tactic strategies, unserved virtues) for the author to pick
interview targets. Mechanics: Explore-subagent fan-out allowed for the
sweeps; keyword grep only shortlists — disposition requires a full read.
Overlap note: /align-audit's draft already covers (a)–(c) style checks
mechanically (digest tables + content-level sampled pass); the
greenfield-relevance gate also runs at /align-tactics finalization. The
inclusion decision is largely whether the unserved-virtue census and the
author-facing candidate menu move into /align-audit or die.
