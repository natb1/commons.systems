# Observation carrier — 2026-08-21 finalize of tactic-align-strategy-new-steps-revision

**This node is not work. Do not dispatch it.** It carries no plan, no units and
no verification, because there is nothing to build. It exists so four immaterial
drift observations from one autonomous round have a durable home that is not the
serving strategy's `clarifications` array, which an autonomous session may not
write (`strategy-graph-native-dispatch` clarification 245 / violation V1,
overturning clarification 118). A human reads these at office hours and decides,
per observation, whether any belongs in the record. See this node's
`office_hours.recommendation` for the three dispositions and a per-observation
first read.

Provenance: `/align-tactics tactic-align-strategy-new-steps-revision`,
2026-08-21, run `wf_ea217473-e83`, against `origin/main` `53eefa33`. The round
**proceeded** — drift returned `proceed: true` with zero parks, the target
finalized to `phase: implement` with a full plan, and both nodes landed in the
same commit.

## Observation 1 — a rename stranded every stored anchor in the retained draft

The draft this round finalized was retained by `/review-fix` of PR #2867 against
`.claude/skills/align-strategy/SKILL.md`. That path no longer exists: commit
`c845d50f` consolidated `/align-strategy` and `/align-init` into `/align`, and
the file is now `.claude/skills/align/SKILL.md`. There is no compatibility stub.
Consequently the node's `statement`, `rationale` and entire body named a retired
skill, and every one of its `SKILL.md:NNN` anchors was stale by roughly +62 to
+72 lines. The `### Dialectic steps` list had also grown from nine items to
eleven, so the draft's prose about "steps 2.4–2.9" no longer enumerated the
file's actual tail.

Judged **immaterial**: re-anchoring is mechanical and changed no scope, and the
draft's informal "2.3"/"2.5" shorthand still resolved because the list is still
numbered 1–N with the gate at 3 and the steelman at 5. The round re-anchored the
whole node and recorded the correction in the target's `rationale`.

Why it is still worth a human's eye: nothing detects this class of staleness. A
draft tactic can sit for weeks while its target file is renamed, split or
consolidated, and the only thing standing between that and a plan built on
fiction is whether the finalizing session happens to check the path exists. Here
it did. The generalization — that a retained draft's `path:line` anchors should
be re-verified, or better, mechanically checked, before a finalize plans from
them — is the MECHANIZE candidate named in the recommendation.

## Observation 2 — positive re-verification of all seven retained findings

All seven findings the draft retained are still substantively present and
unaddressed in the current `.claude/skills/align/SKILL.md`. Two that the
original review recorded as PLAUSIBLE (Finding 4, steelman adoption escaping the
completed gate; Finding 5, a clean gate pass leaving no record) were re-verified
this round against the live file and are now CONFIRMED. The two commits that
touched the file since the draft was filed (`4efe6faf`, `d5bba8b6`) changed
Step 0 and Step 4 only, so no landed change has fixed any finding.

Judged **immaterial**: this is a positive verification confirming the node's
scope is still real work. It gates nothing. Recorded because "we checked, and
none of it was already fixed" is exactly the fact a later reader would otherwise
have to re-derive — and because the sibling failure mode (a draft finalized over
work a sibling already did) is a known one.

## Observation 3 — an earlier NO DEFECT disposition on the same lines, reconciled not overturned

Commit `60bd37ae`, a qa-fix pass on PR #2867 itself, evaluated a QA checklist
item on the doctrinal-consistency gate's prose and closed it **NO DEFECT** after
two independent skeptics verified that the gate's read-set, source restriction,
cross-references and edit-path clause were all present and consistent.

That disposition touches overlapping lines but asserts a **different claim** than
the seven findings. It is about the *presence and clarity* of the gate's
elements. The findings are about *when* the gate runs relative to the content it
tests, *whether* a clean pass is recorded, *what set* "overlapping strategies"
denotes, and *what prose is duplicated* from canonical homes elsewhere in the
file — none of which that pass examined.

Judged **immaterial**: it neither blocks the plan nor needs overturning. The
finalized plan preserves every element that disposition found present, and says
so explicitly in its Context under "Prior disposition this plan does not
overturn," so the plan cannot be read as silently re-litigating a closed item.
Recorded here because the general shape — how a later round should read an
earlier disposition on the same lines that it does not contradict — is a
convention question, not a fact about this node.

needed no separate ratification. Recorded so the next reader knows the
