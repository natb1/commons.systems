# Per-record context capstone review — /reading-review extension owning the selection-bias audit, deferred amend/ratify, and intent-evolution review

Draft context retained verbatim from the 2026-07-08 /align-strategy
context-broadening interview; `/align-tactics` consumes and refines this.

## Shape

- **One capstone per tradition record** (context area), created when the
  record's first context chunk resolves. An ordinary ≤30-minute office-hours
  sitting, resolved like any chunk; it **recurs** — a new capstone may be
  queued — if the area's context later deepens further.
- A context chunk citing several records (`attributes.curriculum.deepens`)
  counts toward **each** cited record's capstone; each capstone reviews the
  shared chunk from its own record's angle. Precedent: chunk 4 already cites
  tradition-plato and tradition-aristotle.

## Duties (deferred from the context chunks)

1. **Selection-bias audit** — were the delegatee-chosen focused excerpts
   representative, judged against the now-read broader context? (The
   2026-07-07 chunk-1 session observed the risk live: Republic VII verified
   partly from 592a-b, outside the chunk's own range.)
2. **Deferred amend/ratify pass** — re-open the record's earlier amend/ratify
   outcomes against the broader context; the reading wins (existing
   clarification on strategy-philosophical-grounding).
3. **Intent-evolution review** — has the author's intent moved since the
   prior reading? Drift in understanding amends the tradition record; drift
   in intent lands as dated clarifications on the affected virtue/strategy
   nodes.

## Integration

- Extends the /reading-review session skill (tactic-reading-review-skill /
  tactic-reading-review-candidate-extension) rather than a new session type;
  stamps last_exercised on delegation-philosophical-articulation like any
  sitting.
