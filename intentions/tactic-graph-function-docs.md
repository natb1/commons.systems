# Document the graph's dual-map / model-of-the-good function doctrine at the entry points — kind-kind rationale and intentions/README.md

Retained draft from the 2026-07-08 /align-strategy graph-function round —
input to a future /align-tactics pass; not yet a plan.

## Context

The 2026-07-08 interview recorded the graph's function doctrine on
strategy-explicit-intent: a dual map (author intention + author knowledge)
and the author's model of the good (one Good, external and never fully
realizable; the virtue forest its imperfect constituent model), serving
self-alignment, capture-avoidance, and delegatee alignment. The graph's
entry points — `intentions/kind-kind.md` (the self-describing entry node)
and `intentions/README.md` — describe structure only; a reader, fork
practitioner, or worker session cannot discover what the graph is *for*
from the entry point.

## Scope (draft)

- `intentions/kind-kind.md`: add a function paragraph to the rationale,
  citing the 2026-07-08 clarifications on strategy-explicit-intent as the
  doctrine's home (kind-kind summarizes, never duplicates).
- `intentions/README.md`: two or three sentences stating the dual-map /
  model-of-the-good function ahead of the structural pointer.
- Constraints: kind-kind is durable human-owned doctrine — the edit needs
  author approval at office-hours before landing. Outward-facing copy stays
  under strategy-author-approved-copy; coordinate with
  tactic-readme-data-structure-first (root README rewrite, separately queued
  and copy-gated) rather than duplicating its framing work.
