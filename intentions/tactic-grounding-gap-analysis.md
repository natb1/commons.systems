# Draft: grounding gap analysis and worker curriculum lane — tick-runnable sensor ranking ungrounded durable-layer nodes by deference/capture; workers draft candidate chunks

Retained interview context for the /align-tactics round that plans this
(2026-07-07 /align-strategy, strategy-complete-grounding):

- **Denominator**: durable-layer nodes only — virtue, strategy, kind,
  delegation. A node is *unmarked* when it carries neither
  `attributes.traditions` nor `attributes.grounding`. Tactics are exempt
  (inherit through the strategy they serve).
- **Ranking**: deference/capture exposure first — nodes tied (by serves,
  recovers, or subject) to delegations with high/moderate
  `attributes.divergence.level`, `irreversibility.gated: true`, or costly
  recovery outrank the rest; virtue roots outrank strategies at equal
  exposure.
- **Worker lane at tick**: compute/refresh the ranked gap report, and author
  draft (phase-absent) candidate curriculum chunks from literature Claude can
  already articulate — following the `tactic-reading-chunk-*` +
  `attributes.curriculum.candidate` convention of the first batch
  (chunks 10–17).
- **Prohibitions** (interview-fixed): workers never write tradition records,
  never apply `attributes.grounding` or `attributes.traditions` marks, never
  run deep-research. Those stay author-side.
- The report's consumer on the author side is
  `tactic-grounding-research-skill` (sibling draft).
