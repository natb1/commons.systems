# Observation: a retained draft tactic's body anchors decay silently before finalize

This node is an **observation carrier**, not planned work. It has no plan body,
carries no `phase`, and must not be dispatched. It exists because the
2026-08-19 `/align-tactics` tactic-mode finalize of
`tactic-provision-worktree-script-tests` produced two **immaterial** drift
observations, and clarification 245 (violation V1, ruled 2026-08-14, extended
2026-08-15) directs the immaterial path to mint one born-parked observation
node serving the strategy rather than writing dated clarifications onto the
strategy autonomously. That ruling supersedes clarification 118, which had
permitted the strategy write.

The finalize itself was **not** interrupted: `proceed` stayed true, both
observations were absorbed into the finalized node's own body, and the round
landed. Nothing here blocks anything.

## The two observations

**(a) The host-file anchor understated the node's own readiness.** The draft's
`## Context` asserted that
`.claude/skills/dispatch-propagate/scripts/test-provision-node-worktree.sh`
"has no `provision-node-worktree` tests to extend — the anchor had drifted."
True when recorded on 2026-07-07; false as of 2026-08-19.
`tactic-provision-exit11-worktree-residue` Unit 2 has since built exactly that
file as the purpose-built harness — 17 numbered cases, CI-wired as its own step
at `.github/workflows/unit-tests.yml:287` — and its header (lines 6–17 and
43–45) explicitly reserves this node's gate-plumbing coverage and records that
it updated the sibling node's `statement` to point at it. The scaffolding the
draft said was missing had been built *for* it.

**(b) The placement-carrier anchor pointed at nothing.** The draft's
`## Placement` deferred with "best folded in as a UNIT of
`tactic-graph-router-transitions`." That carrier has since landed and been
pruned; no node file remains in `intentions/` (only prose references survive in
`tactic-graph-native-dispatch.md`). The deferral therefore named a node that
does not exist. The draft's own recorded fallback — "a standalone tiny tactic
is acceptable under sole-tracker doctrine if that tactic lands first" —
resolved it without an author, which is why this is immaterial rather than a
park of the target.

## The pattern worth an author's eye

A retained draft body is the sole carrier from a recording round to the
finalize session (condition 7 / clarification 31), yet its two most
load-bearing pointers — **the file it names** and **the node it defers to** —
are both plain prose that no validator checks.

- A pruned carrier id sitting in draft prose is invisible to
  `validate-graph`'s prose-reference rules, which key on structural edges only.
- A named-but-since-created file is invisible to everything.

Both decayed in the *same* draft, and both were caught only because the
finalize session measured them by hand against `origin/main` before planning.
Whether that hand-verification is the intended control, or wants a mechanical
floor, is the author's call — see this node's `office_hours.recommendation` for
the three dispositions weighed.
