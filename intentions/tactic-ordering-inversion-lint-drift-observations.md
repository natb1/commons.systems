## Observation carrier — no plan, do not dispatch

This node exists only to hold observations for a human. It has no plan, no
units, and no verification block, and it must never be routed to an implement
lane. It is born parked (`office_hours` set, `phase: null`), which is the
graph-native way of saying "decided human-owned work, not a draft."

The observations below came out of the 2026-08-21 `/align-tactics` per-node
finalize of `tactic-validate-graph-ordering-inversion-lint`. They are
**immaterial** — none of them gated that finalize, which proceeded and landed
the target at `phase: implement`. They are recorded here rather than on
`strategy-graph-integrity` itself because an autonomous per-node session may
not append clarifications to a serving strategy
(`strategy-graph-native-dispatch` clarification 245, violation V1, which
overturned clarification 118 on 2026-08-15). They are recorded here rather
than on the finalized tactic because they are about the *strategy's* record,
not about the lint.

## Observation 1 — every number in the strategy's first-audit clarification has drifted

`strategy-graph-integrity`'s sixth clarification ("What did the first audit run
(emulated this round) find?", recorded 2026-07-09 against `f65bacc1`) states a
set of measurements as settled fact. Measured again at `c192d1bb` on
2026-08-21, each has moved by roughly an order of magnitude:

| Clarification 6 says (2026-07-09) | Live store (2026-08-21, `c192d1bb`) |
| --- | --- |
| 302 nodes | 749 nodes |
| 11 done-but-present tactics | 162 |
| 1 near-duplicate statement pair | 69 |
| 26 + 17 + 14 duplicate-serves sets | 55, still pending |
| ~25 dangling prose node references | resolved by the three-class convention; see Observation 2 |

The duplicate-serves strip is owned by `tactic-serves-inheritance-full-strip`,
still at `phase: implement`, and `kind-tactic` still carries no
serves-inheritance clarification — so the "kind-tactic gains the rule at its
next edit" half of clarification 8 is also still owed.

Nothing here is a defect in the strategy's *substance*; the requirement it
records is unchanged. What has decayed is the snapshot embedded in the prose,
and a reader who trusts it today is reading numbers that are wrong by 2-6x.

## Observation 2 — clarification 7's zero-member class now has four members

The seventh clarification ("How do prose references to node ids stay consistent
with a graph whose tactics prune on completion?") defines a violation class —
"a reference to a target that was never created and is owned by no queued
tactic" — and closes with "none exist as of this round." Per the live digest at
`c192d1bb`, that class now has **4** members. The convention itself is sound and
is not in question; only the empirical claim attached to it has expired.

This is the sharper of the two: unlike the counts in Observation 1, this is a
claim of *zero* that a reader could reasonably treat as an invariant rather
than as a snapshot.

## Observation 3 — the strategy's own signal has still never produced a reading

`strategy-graph-integrity` carries `reading: null` and `rounds: {count: 0}`. Its
enforcing skill (`tactic-align-audit-skill`, `/align-audit`) merged 2026-08-20,
one day before this round, so zero completed cycles is not yet a cadence lapse
under condition 4 — but it does mean the strategy's success signal has never
been exercised end to end, and the threshold ("a cycle completes with zero
undispositioned findings and zero repeats of the prior cycle's findings") has
never been tested against a real run.

This same observation has now been recorded independently by three separate
rounds — see the generalization below.

## Generalization worth the author's eye — the carrier mechanism is accumulating duplicates

This is the **third** born-parked observation carrier minted on
`strategy-graph-integrity` in two days:

- `tactic-graph-digest-quality-followups-drift-observations` (2026-08-20)
- `tactic-validate-graph-empty-store-drift-observations` (2026-08-20)
- this node (2026-08-21)

All three independently report Observation 3. The redirect that produces them
(one carrier per round, minted fresh) is doing exactly what
`strategy-graph-integrity` itself forbids: adding redundant nodes that every
future dialectic round must re-read. The mechanism is owned by
`tactic-align-tactics-immaterial-drift-redirect`, still `status: raw`.

Two candidate rulings, both cheap:

1. **Consolidate** — fold the three carriers into one standing observation node
   per strategy, which later rounds append to.
2. **Append-not-mint** — rule that a round with immaterial observations appends
   to an existing born-parked carrier on the same strategy when one exists, and
   mints only when none does.

Either would also stop the carriers from inflating the strategy's own backlog
count, which `strategyBacklogBand` scores born-parked nodes into.
