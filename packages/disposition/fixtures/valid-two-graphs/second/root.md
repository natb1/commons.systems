## Answer

The one the manifest names first, whatever the ranks say.

## Rationale

This root outranks every node of the first graph -- it is a root, so its
rank is 1.0000 -- and the page still lists the first graph's items above
it, which is what makes rank a within-graph order and the manifest the
between-graph one.
